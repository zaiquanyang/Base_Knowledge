# 242. 有效的字母异位词

**难度:** 简单  
**标签:** 哈希表, 字符串, 排序

**链接:** [LeetCode](https://leetcode.cn/problems/valid-anagram/)

## 题目描述

给定两个字符串 `s` 和 `t` ，编写一个函数来判断 `t` 是否是 `s` 的 字母异位词。

 

**示例 1:**

```

**输入:** s = "anagram", t = "nagaram"
**输出:** true

```

**示例 2:**

```

**输入:** s = "rat", t = "car"
**输出: **false
```

 

**提示:**

	- `1 4`
	- `s` 和 `t` 仅包含小写字母

 

**进阶: **如果输入字符串包含 unicode 字符怎么办？你能否调整你的解法来应对这种情况？
