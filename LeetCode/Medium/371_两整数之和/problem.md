# 371. 两整数之和

**难度:** 中等  
**标签:** 位运算, 数学

**链接:** [LeetCode](https://leetcode.cn/problems/sum-of-two-integers/)

## 题目描述

给你两个整数 `a` 和 `b` ，**不使用 **运算符 `+` 和 `-` ​​​​​​​，计算并返回两整数之和。

 

**示例 1：**

```

**输入：**a = 1, b = 2
**输出：**3

```

**示例 2：**

```

**输入：**a = 2, b = 3
**输出：**5

```

 

**提示：**

	- `-1000
