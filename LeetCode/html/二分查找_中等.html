# 33. 搜索旋转排序数组

**难度:** 中等  
**标签:** 数组, 二分查找

**链接:** [LeetCode](https://leetcode.cn/problems/search-in-rotated-sorted-array/)

## 题目描述

整数数组 `nums` 按升序排列，数组中的值 **互不相同** 。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 
	- `1 
	- `-104 4`
	- `nums` 中的每个值都 **独一无二**
	- 题目数据保证 `nums` 在预先未知的某个下标上进行了旋转
	- `-104 4`

解答方案

from typing import List


class Solution:
    def search(self, nums: List[int], target: int) -> int:
        N = len(nums)
        left, right = 0, N-1

        while left <= right:
            # print(left, right)
            mid = (left + right)//2
            if nums[mid]==target:
                return mid

            # left--->mid 是左半递增区间
            if nums[left] <= nums[mid]:
                if nums[left]<=target<nums[mid]:
                    right=mid-1
                else:
                    left = mid+1
            else: # mid--->right 是递增区间
                if nums[mid]<target<=nums[right]:
                    left = mid+1
                else:
                    right=mid-1
        return -1

# 34. 在排序数组中查找元素的第一个和最后一个位置

**难度:** 中等  
**标签:** 数组, 二分查找

**链接:** [LeetCode](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)

## 题目描述

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

 

**示例 1：**

```

**输入：**nums = [`5,7,7,8,8,10]`, target = 8
**输出：**[3,4]
```

**示例 2：**

```

**输入：**nums = [`5,7,7,8,8,10]`, target = 6
**输出：**[-1,-1]
```

**示例 3：**

```

**输入：**nums = [], target = 0
**输出：**[-1,-1]
```

 

**提示：**

	- `0 5`
	- `-109 9`
	- `nums` 是一个非递减数组
	- `-109 9`

解答方案

from typing import List, Optional


class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        N = len(nums)

        left, right = 0, N-1
        while left<=right:
            mid = (left+right)//2
            if nums[mid] == target:
                target_left, target_right = mid, mid
                
                while left<=(target_left-1):
                    if nums[target_left-1] == target:
                        target_left -= 1
                    else:
                        break
                
                while target_right+1<=right:
                    if nums[target_right+1] == target:
                        target_right += 1
                    else:
                        break

                return target_left, target_right

            if nums[mid]<target<=nums[right]:
                left = mid+1
            else:
                right=mid-1
        return [-1, -1]
